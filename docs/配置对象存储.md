# 配置对象存储

这一页给出直接可用的 S3 兼容存储和阿里云 OSS 配置。密钥建议从环境变量或密钥管理服务读取。

## S3 / R2 / B2 / MinIO

```go
import s3driver "github.com/duolabmeng6/go-filesystem/drivers/s3"

disk, err := s3driver.NewDisk(context.Background(), s3driver.Config{
	Bucket:          os.Getenv("S3_BUCKET"),
	Region:          os.Getenv("S3_REGION"),
	Endpoint:        os.Getenv("S3_ENDPOINT"),
	AccessKeyID:     os.Getenv("S3_ACCESS_KEY_ID"),
	AccessKeySecret: os.Getenv("S3_ACCESS_KEY_SECRET"),
	SessionToken:    os.Getenv("S3_SESSION_TOKEN"),
	BaseURL:         os.Getenv("S3_BASE_URL"),
	UsePathStyle:    true,
	DisableACL:      true,
})
if err != nil {
	return err
}
```

写入和读取：

```go
if err := disk.Put(ctx, "uploads/a.txt", []byte("hello")); err != nil {
	return err
}

data, err := disk.Get(ctx, "uploads/a.txt")
```

生成公开 URL：

```go
url, err := disk.URL(ctx, "uploads/a.txt")
```

生成临时下载 URL：

```go
url, err := disk.TemporaryURL(ctx, "uploads/a.txt", time.Now().Add(15*time.Minute))
```

## Cloudflare R2 推荐配置

```go
disk, err := s3driver.NewDisk(context.Background(), s3driver.Config{
	Bucket:          os.Getenv("R2_BUCKET"),
	Region:          "auto",
	Endpoint:        os.Getenv("R2_ENDPOINT"),
	AccessKeyID:     os.Getenv("R2_ACCESS_KEY_ID"),
	AccessKeySecret: os.Getenv("R2_ACCESS_KEY_SECRET"),
	BaseURL:         os.Getenv("R2_BASE_URL"),
	UsePathStyle:    true,
	DisableACL:      true,
})
```

R2 通常这样配置。公开访问建议通过 R2 自定义域名、访问策略、CDN 或你的应用鉴权控制。

## 阿里云 OSS

```go
import ossdriver "github.com/duolabmeng6/go-filesystem/drivers/oss"

disk, err := ossdriver.NewDisk(ossdriver.Config{
	Bucket:          os.Getenv("OSS_BUCKET"),
	Region:          os.Getenv("OSS_REGION"),
	Endpoint:        os.Getenv("OSS_ENDPOINT"),
	AccessKeyID:     os.Getenv("OSS_ACCESS_KEY_ID"),
	AccessKeySecret: os.Getenv("OSS_ACCESS_KEY_SECRET"),
	SecurityToken:   os.Getenv("OSS_SECURITY_TOKEN"),
	BaseURL:         os.Getenv("OSS_BASE_URL"),
})
if err != nil {
	return err
}
```

OSS 图片处理等参数可以放进临时 URL：

```go
url, err := disk.TemporaryURL(
	ctx,
	"images/a.jpg",
	time.Now().Add(15*time.Minute),
	filesystem.WithURLParameter("x-oss-process", "image/resize,w_800/quality,q_80"),
)
```

## 在一个应用里配置多个存储

```go
manager := filesystem.New(filesystem.WithDefaultDisk("s3"))
manager.MustExtend("s3", s3driver.NewFactory())
manager.MustExtend("oss", ossdriver.NewFactory())

err := manager.ConfigureDisk("s3", filesystem.DiskConfig{
	Driver:  "s3",
	BaseURL: os.Getenv("S3_BASE_URL"),
	Options: map[string]any{
		"bucket":            os.Getenv("S3_BUCKET"),
		"region":            os.Getenv("S3_REGION"),
		"endpoint":          os.Getenv("S3_ENDPOINT"),
		"access_key_id":     os.Getenv("S3_ACCESS_KEY_ID"),
		"access_key_secret": os.Getenv("S3_ACCESS_KEY_SECRET"),
		"use_path_style":    true,
		"disable_acl":       true,
	},
})
```
