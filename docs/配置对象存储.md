# 配置对象存储

推荐用法：业务代码固定使用 `storage` 这个别名，配置决定它指向 S3、R2、B2、MinIO 还是阿里云 OSS。

业务代码始终这样写：

```go
err := manager.Put(ctx, "uploads/a.txt", []byte("hello"))
data, err := manager.Get(ctx, "uploads/a.txt")
```

下面只展示怎么切换配置。

## 把 `storage` 指向 S3 / R2 / B2 / MinIO

```go
import s3driver "github.com/duolabmeng6/go-filesystem/drivers/s3"

manager, err := filesystem.NewFromConfig(ctx, filesystem.Config{
	Default: "storage",
	Disks: map[string]filesystem.DiskConfig{
		"storage": {
			Driver:  "s3",
			BaseURL: os.Getenv("S3_BASE_URL"),
			Options: map[string]any{
				"bucket":            os.Getenv("S3_BUCKET"),
				"region":            os.Getenv("S3_REGION"),
				"endpoint":          os.Getenv("S3_ENDPOINT"),
				"access_key_id":     os.Getenv("S3_ACCESS_KEY_ID"),
				"access_key_secret": os.Getenv("S3_ACCESS_KEY_SECRET"),
				"session_token":     os.Getenv("S3_SESSION_TOKEN"),
				"use_path_style":    true,
				"disable_acl":       true,
			},
		},
	},
}, filesystem.WithDriver("s3", s3driver.NewFactory()))
if err != nil {
	return err
}
```

写入、读取、生成链接：

```go
if err := manager.Put(ctx, "uploads/a.txt", []byte("hello")); err != nil {
	return err
}

data, err := manager.Get(ctx, "uploads/a.txt")

disk, err := manager.DefaultDisk()
if err != nil {
	return err
}

url, err := disk.URL(ctx, "uploads/a.txt")
temporaryURL, err := disk.TemporaryURL(ctx, "uploads/a.txt", time.Now().Add(15*time.Minute))
```

R2 通常这样配置。公开访问建议通过 R2 自定义域名、访问策略、CDN 或你的应用鉴权控制。

## 把 `storage` 指向阿里云 OSS

```go
import ossdriver "github.com/duolabmeng6/go-filesystem/drivers/oss"

manager, err := filesystem.NewFromConfig(ctx, filesystem.Config{
	Default: "storage",
	Disks: map[string]filesystem.DiskConfig{
		"storage": {
			Driver:  "oss",
			BaseURL: os.Getenv("OSS_BASE_URL"),
			Options: map[string]any{
				"bucket":            os.Getenv("OSS_BUCKET"),
				"region":            os.Getenv("OSS_REGION"),
				"endpoint":          os.Getenv("OSS_ENDPOINT"),
				"access_key_id":     os.Getenv("OSS_ACCESS_KEY_ID"),
				"access_key_secret": os.Getenv("OSS_ACCESS_KEY_SECRET"),
				"security_token":    os.Getenv("OSS_SECURITY_TOKEN"),
			},
		},
	},
}, filesystem.WithDriver("oss", ossdriver.NewFactory()))
if err != nil {
	return err
}
```

OSS 图片处理等参数可以放进临时链接：

```go
disk, err := manager.DefaultDisk()
if err != nil {
	return err
}

url, err := disk.TemporaryURL(
	ctx,
	"images/a.jpg",
	time.Now().Add(15*time.Minute),
	filesystem.WithURLParameter("x-oss-process", "image/resize,w_800/quality,q_80"),
)
```
