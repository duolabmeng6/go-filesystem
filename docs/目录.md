# 文档目录

按你要完成的事情选择文档：

- 第一次接入：看 [快速入门](快速入门.md)。
- 保存到本机目录：看 [配置本地磁盘](配置本地磁盘.md)。
- 保存到 S3、R2、B2、MinIO 或 OSS：看 [配置对象存储](配置对象存储.md)。
- 上传、下载、复制、移动、删除、列表：看 [上传下载与文件管理](上传下载与文件管理.md)。
- 返回公开链接或临时下载链接：看 [生成链接](生成链接.md)。
- 写业务测试：看 [测试](测试.md)。
- 上线前配置 Web server、CDN、密钥和存储目录：看 [部署](部署.md)。
- 遇到报错或链接打不开：看 [常见问题](常见问题.md)。
