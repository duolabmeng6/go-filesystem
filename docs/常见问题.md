# 常见问题

## URL 能生成，但浏览器打不开

`URL` 只负责生成字符串。请检查：

- `BaseURL` 是否正确。
- 本地文件是否被 Nginx、框架静态路由或反向代理服务。
- 对象存储访问策略、CDN 或自定义域名是否配置。
- 文件是否真的已经写入对应路径。

## R2 或 B2 设置 public visibility 报错

这类 S3-compatible 服务通常不使用对象 ACL。配置里使用：

```go
DisableACL: true
```

公开访问交给访问策略、CDN、自定义域名或应用鉴权。

## 本地临时 URL 为什么不能直接用

本地文件的签名下载 URL 取决于你的 HTTP 路由和签名规则，所以需要你提供 builder：

```go
TemporaryURLBuilder: func(ctx context.Context, path string, expiresAt time.Time, opts filesystem.URLOptions) (string, error) {
	return signDownloadURL(path, expiresAt), nil
}
```

## 路径为什么被拒绝

请使用对象存储风格的相对路径：

```text
avatars/me.png
reports/2026/05.csv
```

不要使用：

```text
/tmp/a.txt
../a.txt
a//b.txt
a\b.txt
C:\Windows
```

## 如何处理文件不存在

```go
data, err := disk.Get(ctx, "missing.txt")
if errors.Is(err, filesystem.ErrNotFound) {
	return nil
}
if err != nil {
	return err
}
_ = data
```

## 如何禁止覆盖

```go
err := disk.Put(ctx, "reports/a.txt", data, filesystem.WithOverwrite(false))
if errors.Is(err, filesystem.ErrAlreadyExists) {
	return fmt.Errorf("文件已存在")
}
```

## 如何在测试里不写真实云存储

```go
fake := filesystem.Fake(t, manager, "s3")

err := manager.Put(context.Background(), "uploads/a.txt", []byte("hello"))
if err != nil {
	t.Fatal(err)
}

fake.AssertExists("uploads/a.txt")
```
