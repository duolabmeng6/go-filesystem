# 生成公开链接和临时链接

这一页只讲怎么拿到可以返回给用户的链接。

## 公开链接

先配置 `BaseURL`：

```go
disk, err := local.NewDisk(local.Config{
	Root:       "storage/app/public",
	BaseURL:    "https://example.com/storage",
	Visibility: filesystem.VisibilityPublic,
})
```

生成链接：

```go
url, err := disk.URL(ctx, "avatars/me.png")
```

返回：

```text
https://example.com/storage/avatars/me.png
```

路径会自动转义：

```go
url, err := disk.URL(ctx, "docs/hello world#1.txt")
```

返回：

```text
https://example.com/storage/docs/hello%20world%231.txt
```

`BaseURL` 只拼接链接。文件是否能访问，取决于你的 Web server、对象存储公开策略或 CDN。

## S3 临时下载 URL

```go
url, err := disk.TemporaryURL(ctx, "private/report.pdf", time.Now().Add(15*time.Minute))
```

指定下载文件名：

```go
url, err := disk.TemporaryURL(
	ctx,
	"private/report.pdf",
	time.Now().Add(15*time.Minute),
	filesystem.WithURLParameter("response-content-disposition", `attachment; filename="report.pdf"`),
)
```

指定响应类型：

```go
url, err := disk.TemporaryURL(
	ctx,
	"private/report.pdf",
	time.Now().Add(15*time.Minute),
	filesystem.WithURLParameter("response-content-type", "application/pdf"),
)
```

## OSS 临时下载 URL

```go
url, err := disk.TemporaryURL(ctx, "private/report.pdf", time.Now().Add(15*time.Minute))
```

OSS 图片处理：

```go
url, err := disk.TemporaryURL(
	ctx,
	"images/a.jpg",
	time.Now().Add(15*time.Minute),
	filesystem.WithURLParameter("x-oss-process", "image/resize,w_800/quality,q_80"),
)
```

## 本地临时下载 URL

本地临时 URL 需要你提供签名逻辑：

```go
disk, err := local.NewDisk(local.Config{
	Root: "storage/app/private",
	TemporaryURLBuilder: func(ctx context.Context, path string, expiresAt time.Time, opts filesystem.URLOptions) (string, error) {
		return signDownloadURL(path, expiresAt), nil
	},
})
```

然后一样使用：

```go
url, err := disk.TemporaryURL(ctx, "invoices/a.pdf", time.Now().Add(15*time.Minute))
```

## 过期时间必须在未来

```go
_, err := disk.TemporaryURL(ctx, "a.txt", time.Now().Add(-time.Minute))
if errors.Is(err, filesystem.ErrInvalidExpiration) {
	return fmt.Errorf("过期时间必须在未来")
}
```
