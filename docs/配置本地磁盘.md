# 配置本地磁盘

本地磁盘适合开发环境、单机应用、临时文件、私有下载和由 Web server 直接服务的公开文件。

## 私有目录

```go
disk, err := local.NewDisk(local.Config{
	Root:       "storage/app/private",
	Visibility: filesystem.VisibilityPrivate,
})
if err != nil {
	return err
}
```

写入文件：

```go
if err := disk.Put(ctx, "reports/a.txt", []byte("hello")); err != nil {
	return err
}
```

## 公开目录

```go
disk, err := local.NewDisk(local.Config{
	Root:       "storage/app/public",
	BaseURL:    "/storage",
	Visibility: filesystem.VisibilityPublic,
})
if err != nil {
	return err
}

if err := disk.Put(ctx, "avatars/me.png", data, filesystem.WithVisibility(filesystem.VisibilityPublic)); err != nil {
	return err
}

url, err := disk.URL(ctx, "avatars/me.png")
```

`BaseURL` 只生成字符串。你还需要让 Web server 或框架把 `storage/app/public` 暴露到 `/storage`。

Nginx 示例：

```nginx
location /storage/ {
    alias /srv/myapp/storage/app/public/;
    try_files $uri =404;
}
```

## 自定义权限

```go
disk, err := local.NewDisk(local.Config{
	Root: "storage/app",
	Permissions: local.Permissions{
		FilePublic:  0o644,
		FilePrivate: 0o600,
		DirPublic:   0o755,
		DirPrivate:  0o700,
	},
})
```

一般情况下可以不传 `Permissions`，默认值已经适合大多数应用。

## 禁止覆盖已有文件

```go
err := disk.Put(ctx, "reports/a.txt", []byte("hello"), filesystem.WithOverwrite(false))
if errors.Is(err, filesystem.ErrAlreadyExists) {
	return fmt.Errorf("文件已存在")
}
```

## 本地临时下载 URL

本地文件没有统一的签名方式，需要你按自己的 HTTP 路由生成。

```go
disk, err := local.NewDisk(local.Config{
	Root: "storage/app/private",
	TemporaryURLBuilder: func(ctx context.Context, path string, expiresAt time.Time, opts filesystem.URLOptions) (string, error) {
		return signDownloadURL(path, expiresAt), nil
	},
})
```

使用时：

```go
url, err := disk.TemporaryURL(ctx, "invoices/a.pdf", time.Now().Add(15*time.Minute))
```

## 常用建议

- 私有文件目录不要放进静态文件根目录。
- 公开文件目录需要由 Web server、框架静态路由或反向代理真实服务。
- 多实例共享文件时，优先使用对象存储，不要依赖单机本地目录。
