# 上传下载与文件管理

这一页按业务动作列出常用写法。

## 写入小文件

```go
err := disk.Put(ctx, "docs/a.txt", []byte("hello"))
```

设置公开 visibility：

```go
err := disk.Put(ctx, "avatars/me.png", data, filesystem.WithVisibility(filesystem.VisibilityPublic))
```

禁止覆盖：

```go
err := disk.Put(ctx, "docs/a.txt", []byte("hello"), filesystem.WithOverwrite(false))
if errors.Is(err, filesystem.ErrAlreadyExists) {
	return fmt.Errorf("文件已存在")
}
```

## 上传大文件

```go
file, err := os.Open("large.zip")
if err != nil {
	return err
}
defer file.Close()

err = disk.Write(ctx, "packages/large.zip", file)
```

## 读取文件

```go
data, err := disk.Get(ctx, "docs/a.txt")
```

大文件建议使用流式读取：

```go
rc, err := disk.Open(ctx, "packages/large.zip")
if err != nil {
	return err
}
defer rc.Close()

_, err = io.Copy(w, rc)
```

## 判断文件是否存在

```go
exists, err := disk.Exists(ctx, "docs/a.txt")
if err != nil {
	return err
}
if !exists {
	return fmt.Errorf("文件不存在")
}
```

## 删除文件

```go
err := disk.Delete(ctx, "docs/a.txt")
```

不存在也不报错：

```go
err := disk.DeleteIfExists(ctx, "docs/a.txt")
```

批量删除：

```go
err := disk.DeleteMany(ctx, []string{
	"tmp/a.txt",
	"tmp/b.txt",
}, filesystem.WithIgnoreMissing())
```

## 复制和移动

```go
err := disk.Copy(ctx, "docs/a.txt", "docs/a-copy.txt")
```

```go
err := disk.Move(ctx, "docs/a-copy.txt", "archive/a.txt")
```

## 读取文件信息

```go
info, err := disk.Stat(ctx, "docs/a.txt")
if err != nil {
	return err
}

fmt.Println(info.Size)
fmt.Println(info.LastModified)
```

快捷方法：

```go
size, err := disk.Size(ctx, "docs/a.txt")
modifiedAt, err := disk.LastModified(ctx, "docs/a.txt")
mime, err := disk.MimeType(ctx, "docs/a.txt")
```

## 列出文件

列出当前目录下的文件：

```go
files, err := disk.Files(ctx, "docs")
```

递归列出全部文件：

```go
files, err := disk.AllFiles(ctx, "docs")
```

分页列表：

```go
page, err := disk.ListPage(ctx, "docs", filesystem.WithPageSize(100))
if err != nil {
	return err
}

if page.NextCursor != "" {
	next, err := disk.ListPage(ctx, "docs", filesystem.WithPageSize(100), filesystem.WithCursor(page.NextCursor))
	_ = next
	_ = err
}
```

## 创建和删除目录

```go
err := disk.MakeDirectory(ctx, "reports/2026")
```

```go
err := disk.DeleteDirectory(ctx, "reports/2026")
```

业务上可以照常按目录路径使用。对象存储不适合依赖空目录长期存在。

## 路径怎么写

使用相对路径：

```text
avatars/user-1.png
reports/2026/05.csv
```

不要传：

```text
/absolute/path
../secret.txt
a//b.txt
a\b.txt
C:\Windows
```

这些路径会被拒绝。
