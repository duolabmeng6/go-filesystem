# 部署

这一页列出上线时最容易漏掉的配置。

## 本地公开文件

代码里配置：

```go
disk, err := local.NewDisk(local.Config{
	Root:       "/srv/myapp/storage/public",
	BaseURL:    "https://example.com/storage",
	Visibility: filesystem.VisibilityPublic,
})
```

Nginx 配置：

```nginx
location /storage/ {
    alias /srv/myapp/storage/public/;
    try_files $uri =404;
}
```

应用里：

```go
url, err := disk.URL(ctx, "avatars/me.png")
```

## 本地私有文件

私有目录不要暴露给静态文件服务：

```go
disk, err := local.NewDisk(local.Config{
	Root:       "/srv/myapp/storage/private",
	Visibility: filesystem.VisibilityPrivate,
})
```

下载时走应用鉴权：

```go
func Download(disk *filesystem.Disk) http.HandlerFunc {
	return func(w http.ResponseWriter, r *http.Request) {
		rc, err := disk.Open(r.Context(), "invoices/a.pdf")
		if errors.Is(err, filesystem.ErrNotFound) {
			http.NotFound(w, r)
			return
		}
		if err != nil {
			http.Error(w, "download failed", http.StatusInternalServerError)
			return
		}
		defer rc.Close()

		w.Header().Set("Content-Type", "application/pdf")
		_, _ = io.Copy(w, rc)
	}
}
```

## 对象存储公开文件

```go
disk, err := s3driver.NewDisk(context.Background(), s3driver.Config{
	Bucket:          os.Getenv("S3_BUCKET"),
	Region:          os.Getenv("S3_REGION"),
	Endpoint:        os.Getenv("S3_ENDPOINT"),
	AccessKeyID:     os.Getenv("S3_ACCESS_KEY_ID"),
	AccessKeySecret: os.Getenv("S3_ACCESS_KEY_SECRET"),
	BaseURL:         "https://cdn.example.com",
	UsePathStyle:    true,
	DisableACL:      true,
})
```

上线前确认：

- `BaseURL` 是用户可以访问的 CDN 或自定义域名。
- 对象存储访问策略、CDN 规则或应用鉴权已经配置好。
- 密钥来自环境变量、密钥管理服务或云平台身份。
- R2/B2 这类服务通常使用 `DisableACL: true`。

## 容器部署

本地磁盘：

- 给 storage 目录挂载持久化 volume。
- 确保应用运行用户有读写权限。
- 多实例共享文件时，优先改用对象存储。

对象存储：

- 每个环境使用不同 bucket 或 prefix。
- 给请求 context 设置超时。
- 临时文件和测试 prefix 配置生命周期清理。

## 多租户目录

```go
tenantDisk, err := manager.Build(ctx, filesystem.DiskConfig{
	Driver:     "s3",
	PathPrefix: "tenants/" + tenantID,
	Options: map[string]any{
		"bucket": os.Getenv("S3_BUCKET"),
		"region": os.Getenv("S3_REGION"),
	},
})
```

业务里只写相对路径：

```go
err := tenantDisk.Put(ctx, "avatars/me.png", data)
```

## 发布前检查

- `go test ./...` 已通过。
- `BaseURL` 在浏览器里能访问。
- 私有文件没有暴露到静态目录。
- 生产密钥没有写进代码。
- 上传路径由业务代码生成，不直接信任用户输入。
