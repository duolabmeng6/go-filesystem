# 测试

业务测试里通常不应该真的写 S3 或 OSS。用 Fake 替换 disk，测试结束自动恢复。

## 替换 Manager 里的 disk

```go
func TestUploadAvatar(t *testing.T) {
	manager := filesystem.New(filesystem.WithDefaultDisk("local"))
	manager.MustExtend("local", local.NewFactory())
	_ = manager.ConfigureDisk("local", filesystem.DiskConfig{
		Driver: "local",
		Root:   t.TempDir(),
	})

	fake := filesystem.Fake(t, manager, "local")

	err := manager.Put(context.Background(), "avatars/me.png", []byte("png"))
	if err != nil {
		t.Fatal(err)
	}

	fake.AssertExists("avatars/me.png")
	fake.AssertContent("avatars/me.png", []byte("png"))
}
```

测试文件里需要导入：

```go
import (
	"testing"

	"github.com/duolabmeng6/go-filesystem"
	"github.com/duolabmeng6/go-filesystem/local"
)
```

## 断言文件数量

```go
fake.AssertCount("avatars", 1)
```

## 断言目录为空

```go
fake.AssertDirectoryEmpty("tmp")
```

## 保留测试文件方便排查

```go
root := filepath.Join(os.TempDir(), "go-filesystem-debug")

fake, err := filesystem.PersistentFake(manager, "local", root)
if err != nil {
	t.Fatal(err)
}

_ = fake
```

`PersistentFake` 不会自动删除目录。

## 被测代码直接接收 Disk

```go
func SaveAvatar(ctx context.Context, disk *filesystem.Disk, data []byte) error {
	return disk.Put(ctx, "avatars/me.png", data)
}
```

测试：

```go
func TestSaveAvatar(t *testing.T) {
	disk := filesystem.NewFakeDisk(t)

	if err := SaveAvatar(context.Background(), disk.Disk, []byte("png")); err != nil {
		t.Fatal(err)
	}

	disk.AssertExists("avatars/me.png")
}
```

## 运行全部测试

```sh
go test ./...
```

真实云存储集成测试需要环境变量。一般业务项目不建议默认跑真实云存储测试。
